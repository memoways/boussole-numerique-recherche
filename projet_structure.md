## Sections

### 1. Hero
- Titre : "Description du projet — Boussole Numérique Culture"
- Sous-titre : "Un outil web gratuit pour aider les acteurs culturels genevois à évaluer leurs pratiques numériques, identifier leurs priorités et cheminer vers de meilleures façons de travailler — sans expertise technique préalable."

### 2. Note d'intention — "Un outil pour voir où l'on en est"
- Texte : La Boussole Numérique Culture est une application web interactive et gratuite...
- Repose sur un questionnaire adaptatif d'une dizaine de minutes, suivi d'une restitution visuelle et d'un dialogue guidé par une IA spécialement conçue pour le réalité du secteur culturel.
- Ce n'est ni un audit, ni un cours, ni un chatbot généraliste : c'est un miroir lucide et bienveillant
- Projet émane de Memoways, agence genevoise spécialisée...
- Citation : "Ce qu'on peut évaluer, on peut l'améliorer — et l'amélioration se mesure."

### 3. Le contexte — "Des pratiques numériques qui coûtent cher en énergie créative"
- Texte sur les problèmes actuels (fichiers Word, versions, stress...)
- Schéma interactif : "Problématiques fréquentes et leur résolution"
  - Tableau 2 colonnes : Situation actuelle fréquente | Avec les bons outils et pratiques
  - 5 lignes : Documents Word/email 7 versions → Un seul fichier partagé
  - Stress retrouver bonne version → Recherche instantanée, historique
  - Processus manuels répétitifs → Automatisations
  - Communication fragmentée → Un espace de travail commun
  - Difficulté savoir par où commencer → Un diagnostic personnalisé

### 4. La proposition — "Ce que fait la Boussole, concrètement"
- Texte : expérience conversationnelle guidée — pas un formulaire classique
- Évoluera avec partenaires, expérimentations, retours premiers pilotes

### 5. Les 5 dimensions évaluées (grille 2 colonnes)
- Outils & méthodes de travail
- Compétences & culture numérique
- Données, archivage & documentation
- Médiation, publics & communication
- Partage & cohérence des pratiques
- (6e case) : Les questions s'appuient sur des micro-scénarios réalistes du "quotidien culturel" — pas de jargon technique.

### 6. Les 3 temps de l'expérience — Parcours utilisateur
- Sélecteur : "Acteur·trice culturel·le genevois·e"
- Deux modes : Mode individuel / Mode structure
- 3 étapes dépliables :
  1. La Photo (10-15 min · Quiz d'exploration)
  2. Le Panorama (Restitution visuelle immersive)
  3. L'Approfondissement (Avec compte détaillé · Suivi dans le temps)
- Note : "Depuis la première étape, l'expérience est conçue pour être accessible sans aucune compétence technique préalable."

### 7. Mode collaboratif — "Donner la parole à toute une équipe"
- Texte : Pour les compagnies, associations et collectifs, la Boussole propose un mode collaboratif
- Plusieurs personnes de la même structure répondent individuellement au questionnaire
- L'IA synthétise l'ensemble → carte des perceptions croisées
- Panneau orange "Comment ça marche en mode structure" :
  1. Chaque membre de l'équipe répond individuellement (10-15 min)
  2. Les réponses sont agrégées et analysées par IA
  3. Une synthèse collective est générée : consensus et points de friction
  4. Des priorités partagées émergent pour guider les décisions

### 8. Positionnement — "La Boussole face aux autres solutions"
- Intro : Pourquoi créer un nouvel outil alors qu'il en existe déjà ?
- Tableau comparatif avec onglets : Tous | Adapté au secteur | Accessibilité | Coût | Données | Fonctionnalités
- Colonnes : ChatGPT / IA généraliste | Audit externe | Formation en ligne | Boussole ✓
- Critères : Adapté au secteur culturel, Accessible sans expertise, Gratuit, Données hébergées en Suisse, Restitution visuelle personnalisée, Mode collaboratif, Recommandations vers l'écosystème local
- Note : "Tableau ActuallyAI basé sur une analyse de février 2026."

### 9. Principes fondateurs — "Un projet de service public"
- 6 cartes :
  - Gratuit
  - Données souveraines (Suisse/Europe)
  - Confidentialité
  - Neutralité
  - Open source (GitHub)
  - Approche contributive

### 10. Architecture technique — "Comment la Boussole est construite"
- Texte intro sur souveraineté, transparence, pérennité
- Schéma "Architecture de la Boussole — Vue d'ensemble" (toggleable)
  - Interface utilisateur : Interface web (React/Tailwind), Saisie vocale (Futur), Design adaptatif
  - Intelligence artificielle (le cerveau) : Agent IA, Base de ressources, Modèle de scoring
  - Données & hébergement (Suisse) : Serveur Infomaniak, Base de données (Suisse/Europe)
  - Transparence & partage : Code open source sur GitHub

### 11. Calendrier — "Développement en 4 phases sur 2 ans"
- 4 phases verticales :
  1. Mois 1-3 : MVP (questionnaire adaptatif 5 dimensions, saisie vocale, restitution visuelle, export PDF, mode conversationnel guidé)
  2. Mois 4 : Beta test (tests avec structures culturelles pilotes genevoises, ajustements UX, base de ressources)
  3. Mois 5-8 : Version 2 (mode structure collaboratif, upload documents, enrichissement base ressources)
  4. Mois 9-24 : Exploitation & amélioration continue (comparaison anonymisée, optimisations, extension partenariats. Objectif 500 utilisateurs inscrits)

### 12. Objectifs à 2 ans
- 4 points (fond bleu) :
  - 500 utilisateurs inscrits, dont 50% utilisent l'outil régulièrement
  - Un relai actif par les partenaires institutionnels genevois
  - Une base de connaissances enrichie par la communauté et les retours d'usage
  - Des données anonymisées permettant un diagnostic de l'écosystème culturel genevois
- Panneau orange "Et au-delà de Genève" :
  - Si les retours sont positifs, des financements complémentaires permettront d'étendre l'outil en Suisse romande
  - Code open source, d'autres villes ou cantons pourront le reprendre et l'adapter à leur contexte
  - Servir un portail de service public qui investit sur le long terme dans l'outillage des acteurs culturels sous cette forme
