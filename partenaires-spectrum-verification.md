# Vérification visuelle — page Partenaires

Le contrôle visuel confirme l'application d'une progression **bleu → cyan → vert → vert olive → orange** sur les cartes « Qui peut contribuer » et les cinq étapes du parcours. Les étapes restent lisibles et ordonnées de gauche à droite, avec le texte sombre sur les fonds vert et vert olive plus clairs.

Les cartes « Pourquoi participer » utilisent les trois premières teintes du spectre. Les partenaires confirmés et les listes d'apports reprennent la même grammaire colorée. Les CTA restent orange afin de préserver leur rôle d'action principal.
