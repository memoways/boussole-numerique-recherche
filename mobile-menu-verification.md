# Vérification mobile — menu de navigation

Contrôle réalisé à **390 px** et **320 px** de largeur de viewport. Le menu fermé conserve uniquement le logo et le bouton burger ; aucune entrée de navigation ne déborde horizontalement.

Lorsque le burger est ouvert, les six entrées attendues apparaissent dans cet ordre : Projet, Calendrier, Expérience, Méthode, Partenaires, puis le bouton « Suivre le projet ». L'entrée Calendrier mène bien vers `/timeline` et le menu se referme automatiquement après la navigation.
